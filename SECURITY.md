# Security

Kekkai keeps a cooperative agent within its task; it is not a sandbox (see [docs/LIMITATIONS.md](docs/LIMITATIONS.md)).
A way for the agent to edit outside its scope through the edit tools without a refusal, to change its scope without
the tools, or to make the hook allow what the agent's permissions would ask, is a vulnerability.

Report it privately through GitHub's *Report a vulnerability* (Security tab of the repository), not in a public
issue.
