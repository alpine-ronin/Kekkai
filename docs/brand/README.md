# Kekkai's logo

The mark is a selection drawn inside the project, in vermilion, with the change held in the middle of it: the scope
the agent declared and the edit it keeps to. It is drawn like [Airlock](https://github.com/alpine-ronin/airlock)'s
and [phpgraph](https://github.com/alpine-ronin/phpgraph)'s: the same tile, stroke and round caps, ink and paper, one
accent. Vermilion is the colour of the torii, the gate that marks a boundary.

| File | Use |
|---|---|
| `logo.svg` | The lockup (mark and wordmark) on light backgrounds |
| `logo-dark.svg` | The lockup on dark backgrounds |
| `mark.svg`, `mark-dark.svg` | The mark alone, on light or dark backgrounds |
| `icon.svg` | The app icon: the mark on a dark tile |
| `icon-512.png` | The avatar (square; GitHub rounds it) |
| `social-preview.png` | The repository's social preview, 1280 × 640 |

The wordmark is drawn as paths, so the SVGs need no font: Space Grotesk SemiBold for `kekkai`, JetBrains Mono for
the tagline on the social preview (both under the SIL Open Font License).

| Colour | Hex |
|---|---|
| Ink | `#12161C` |
| Paper | `#F6F5F1` |
| Vermilion, on light | `#C23B22` (4.9:1 on paper) |
| Vermilion, on dark | `#F07A62` (6.6:1 on ink) |

On GitHub: the social preview is set in the repository's Settings, General, Social preview.
